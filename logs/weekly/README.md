# Optional Weekly Logs

## Purpose and cadence

Weekly logs are optional snapshots for continuity, not a rigid schedule or a requirement to manufacture progress. Create a dated log only when it usefully records work, Evidence, changed Interpretation, failure, a Decision, or a blocker. Enabling any recurring review remains a separate explicit choice.
