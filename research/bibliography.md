# Bibliography

## Current status

No verified bibliographic records are documented. Do not add a remembered reference as if it were verified; keep an unverified lead outside the confirmed bibliography until its bibliographic identity and accessible Source have been checked.

## Required record

Use one record per Source with these fields:

| Field | Required content |
| --- | --- |
| Citekey | Stable local key; do not silently reuse it for another Source. |
| Full citation | Complete citation in the project’s selected style, copied or constructed only from verified metadata. |
| DOI/URL | Persistent DOI where available, otherwise the verified Source URL. |
| Source type | For example: journal article, book, chapter, proceedings paper, thesis, standard, project documentation, or dataset. |
| Verification status | `Verified against source`, `Metadata verified; full text not checked`, or `Unverified lead — not admissible as confirmed Source`. |
| Access date | ISO date (`YYYY-MM-DD`) on which the DOI, URL, or full text was checked. |
| Linked reading note | Repository path to a note based on the [reading-note template](reading-notes/README.md). |
| Related question/claim | One or more stable links to [Q0–Q5](../questions/question-tree.md) and/or [C1–C5](../claims-and-evidence/evidence-matrix.md), or `Not yet linked`. |
| Use in thesis | Intended argumentative or methodological use; label this as an Interpretation until the use is substantiated. |

## Admission and revision rules

- Verify author or organization, title, publication venue or publisher, year, and DOI/URL before marking a record verified.
- A bibliography record establishes Source provenance; it is not automatically Evidence for a claim.
- Do not infer findings from an abstract or metadata page. Record the access limitation.
- Preserve corrections visibly when a citekey or citation changes, and update the linked reading note.
- Candidate quotations remain in reading notes and require a page or location marker.
