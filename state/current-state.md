# Current State

## One-sentence position

The provisional thesis position is that an adaptive architectural boundary may respond to human trajectory signals while preserving occupants’ capacity to negotiate, resist, or reinterpret its actions; this is a framing Hypothesis, not a supported finding.

## Active inquiry
